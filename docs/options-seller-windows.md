# 期权卖方窗口提醒说明（Sell Put / Sell Call · 激进恐慌卖方版）

> 代码实现：[monitoring/config.py](../monitoring/config.py)（`OPTIONS_SIGNAL_CONFIG`、`ALERT_THRESHOLDS`）、[monitoring/alerts.py](../monitoring/alerts.py)（`evaluate_options_window`、`evaluate_alerts`、`format_alert_parts`、`process_alerts`、`build_status_message`）、[scripts/fetch_dashboard.py](../scripts/fetch_dashboard.py)、[index.html](../index.html)（`computeOptionsWindow`、`render`、`renderAlerts`）

## 1. 设计定位与原则

本模块是面向**美股科技 / 成长股与宽基期权卖方**的轻量级大盘环境提醒（零新增数据源、零新增独立大卡），完全复用仪表盘已拉取的 `VIX`、`VVIX`、`SKEW`、`VIX/VIX3M`、`VRP (VIX - RV20)`、`MOVE`、`HY OAS` 与 `SPX RSI(14) / MA200`。

采用**「相对激进 · 恐慌做卖方收高权利金」**口径：
- **恐慌出肥肉时敢提醒**：不等波动率彻底回落再提示，尽量在隐含波动率抬升、期限结构趋近/进入倒挂时更早给出 `Sell Put` 窗口，以及在高波反抽期给出 `Sell Call` 窗口；
- **系统性崩盘时硬熔断**：只在信用市场明显撕裂、股债极端共振或实际波动大幅击穿隐含波动时一票否决 `Sell Put`，防范尾部穿仓；
- **非打扰机会通道**：与红色/橙色系统风险告警清晰隔离，飞书使用蓝色 / 靛蓝卡片，Bark 使用 `active`（不突破勿扰模式），带 24 小时去重且窗口关闭不发“解除”噪音。

## 2. Sell Put 恐慌卖方窗（`opt_sell_put`）

### 2.1 系统性风险硬熔断（一票否决）

满足以下**任意一条**即熔断：不触发 `Sell Put` 提醒，Hero 顶部显示红色 **`慎卖 Put · 系统性风险熔断`**：

| 熔断条件 | 阈值 | 原因 |
| --- | --- | --- |
| 高收益债信用利差 | `HY OAS ≥ 600bp` | 企业违约定价已脱离权益局部恐慌，进入系统性信用风险 |
| 高收益债急速走阔 | `HY OAS 5 日变动 ≥ +75bp` | 信用市场正在快速失血，谨防流动性踩踏 |
| 股债极端共振 | `MOVE ≥ 155` 且 `VIX ≥ 35` | 股债双杀级别波动，卖 Put 易遭连续穿仓 |
| 隐波被实波大幅击穿 | `VRP (VIX - RV20) < -5.0` | 标普 20 日实际波动远高于期权隐含定价，卖方无溢价保护 |

### 2.2 两档机会触发（未触及硬熔断时）

| 档位 | 页面 / 推送标签 | 触发条件 |
| --- | --- | --- |
| **高溢价黄金窗**（`critical`） | `Sell Put · 高溢价黄金窗`<br>飞书靛蓝卡 / Bark `active` | 同时满足：<br>1. `VIX ≥ 26`（或近 1 年分位 `≥ 85%` 且 `VIX ≥ 20`）<br>2. `VIX / VIX3M ≥ 1.00`（期限倒挂，近端权利金肥厚）<br>3. `VRP ≥ +1.0`（若 `VIX ≥ 30` 极端恐慌，放宽至 `VRP ≥ -3.0`；无 VRP 时默认放行）<br>4. `HY OAS < 500bp` 且 `MOVE < 135`（债信稳健，偏权益单边恐慌） |
| **恐慌卖方窗**（`warning`） | `Sell Put · 恐慌卖方窗`<br>飞书蓝卡 / Bark `active` | 满足以下两类之一：<br>• **波动率溢价窗**：`VIX ≥ 20`（或分位 `≥ 70%` 且 `VIX ≥ 18`）且 `VRP ≥ 0`，叠加任一：`VIX/VIX3M ≥ 0.95`、`SPX RSI(14) ≤ 45` 或 `VIX 单日 ≥ +12%`<br>• **深度超跌兜底**：`SPX RSI(14) ≤ 35` 且 `VIX ≥ 18` |

### 2.3 节奏辅助标注

当 `Sell Put` 窗口触发时，系统自动附带一条节奏提示：
- **`VIX` 当日收跌 或 `VVIX` 单日 ≤ -3%**：附注 **「波动率现拐头，利于吃降波」**（右侧 Vol Crush 信号）；
- **`VIX` 单日 ≥ +15%**：附注 **「仍在急升脉冲中，宜分批拉远行权价」**（提醒控制仓位与 Delta）。

## 3. Sell Call 备兑收租窗（`opt_sell_call`）

面向已有正股的 **Covered Call（备兑收租 / 高位锁利）**，同时覆盖“牛市高位过热”与“高波期反弹收肥权利金”两类高赔率场景。

### 3.1 防地板卖飞熔断

满足以下**任意一条**即禁止提示 `Sell Call`（`恐慌砸盘防地板卖飞`）：
- `SPX RSI(14) ≤ 40`
- `VIX / VIX3M ≥ 1.05` 且标普当日收跌（或无涨跌幅）

### 3.2 两类场景与两档触发

| 场景 | 档位 | 标签 | 触发条件 |
| --- | --- | --- | --- |
| **A. 高位过热锁利** | 强信号（`critical`） | `过热锁利窗` | `SPX RSI(14) ≥ 72` 且 `距 MA200 ≥ +10%` |
| **A. 高位过热锁利** | 机会窗（`warning`） | `高位收租窗` | `SPX RSI(14) ≥ 65`，且满足任一：`距 MA200 ≥ +5%`、`SKEW ≥ 140`、或「股涨波升」（`SPX ≥ +0.4%` 且 `VIX ≥ +3%`） |
| **B. 高波反抽收租** | 强信号（`critical`） | `肥波反抽窗` | `VIX ≥ 25` 且 `SPX RSI(14)` 在 `50–65` 且 `SPX 单日 ≥ +1.0%` |
| **B. 高波反抽收租** | 机会窗（`warning`） | `高波反抽窗` | `VIX ≥ 20` 且 `SPX RSI(14)` 在 `48–65`，且满足任一：`SPX 单日 ≥ +0.5%` 或（`SPX < MA200` 且 `RSI ≥ 50`） |

### 3.3 双卖机会窗（`both`）

当同一交易日**同时触发 `Sell Put` 与 `Sell Call`**（典型出现在高波动震荡反抽期，如 `VIX 25+`、`VIX/VIX3M ≥ 0.95` 且标普温和反抽至 `RSI 50–60`），顶部 Hero 胶囊直接合并展示为 **`双卖机会窗（Sell Put + Sell Call）`**，提示双端权利金均处高位。

## 5. 展示与推送行为

1. **仪表盘顶部 Hero 归因区**：在跨市场归因下方内嵌单行「期权卖方窗」提示条（蓝色为机会窗、红色为系统性熔断、灰色为中性观望），不新增独立大卡。
2. **风控中心**：`Sell Put 恐慌卖方窗` 与 `Sell Call 备兑收租窗` 展示在实时预警面板前两格，使用蓝色系徽章区分「高溢价窗 / 强信号窗 / 机会窗口 / 等待窗口」。
3. **自动推送与手动推送**：
   - 服务端定时拉取触发时自动推飞书（蓝 / 靛蓝头）+ Bark（`active` 级别，不破勿扰）；
   - 同级 24 小时去重，机会窗→黄金窗升级立即推送，窗口关闭不发“解除”通知；
   - 点击手动「飞书推送 / Bark 推送」汇总时，消息正文自动附带 `期权卖方窗口` 一行。

## 6. 参数调优与一致性校验

所有阈值集中在两处镜像定义（运行时前端优先读取服务端下发的 `data.config.options_signal`）：
- 后端单一事实源：[monitoring/config.py](../monitoring/config.py) 的 `OPTIONS_SIGNAL_CONFIG` 与 `ALERT_THRESHOLDS["opt_sell_put" | "opt_sell_call"]`
- 前端兜底默认值：[index.html](../index.html) 的 `DEFAULT_OPTIONS_SIGNAL` 与 `DEFAULT_ALERT_THRESHOLDS`

修改任何阈值后，执行以下命令验证前后端 1:1 一致性：

```bash
python3 -m unittest discover -s tests -v
```
