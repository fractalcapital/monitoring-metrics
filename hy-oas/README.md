# 高收益债信用利差（HY OAS）可视化

页面：[index.html](index.html)（另见仓库根目录 [README.md](../README.md)）

## 一句话

**HY OAS 是企业借钱要比美债多付多少利差，测的是违约担忧和资金链紧张程度。**

全名 ICE BofA US High Yield Index Option-Adjusted Spread（FRED: BAMLH0A0HYM2），单位是基点（bp）：

> 高收益债收益率 = 美债收益率 + 利差（OAS）

OAS 是扣掉 embedded option 影响后的利差，所以能跨时期比较。

## 为什么它能看出 VIX 看不到的内伤

- 股市跌、利差不扩：大概率还是情绪和估值调整
- 利差快速走扩：说明企业融资变贵、违约担忧起来了，那才是系统性风险

VIX 完全不反映这个。

## 读数区间

| HY OAS | 区间 | 含义 |
| --- | --- | --- |
| < 300bp | 偏低 | 融资顺畅，违约担忧小 |
| 300–500bp | 正常偏高 | 典型区间 |
| 500–800bp | 高 | 压力明显 |
| 800–1,000bp | 很高 | 衰退 / 流动性紧张 |
| > 1,000bp | 极端 | 危机级别 |

## 历史峰值（代表性约数）

| 事件 | HY OAS |
| --- | --- |
| 2008 金融危机 | 约 2,150bp |
| 2020 新冠疫情 | 约 1,090bp |
| 2002 年 | 约 1,040bp |
