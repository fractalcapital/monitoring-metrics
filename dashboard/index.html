关于 3+2 监控仪表盘

聚焦跨市场交叉验证：以股债波动（VIX / MOVE）与高收益信用利差（HY OAS）确认系统性压力，以 VVIX 与 SKEW 捕捉波动率弹性与机构尾部风险定价。

更新节奏：美国 VPS 每日美股收盘后定时拉取两次（UTC 21:30 / 23:30）写入 data.json；页面平时每 30 分钟自动刷新，收盘拉取窗口（北京时间 05:30–06:00、07:30–08:00）每 1 分钟刷新。点“刷新”经 VPS 接口（api.infidea.app）实时拉取。

数据源与口径

Futu CLI / CBOE CDN：美区 VPS 优先通过 Futu CLI 获取 VIX / VVIX / SKEW / 标普 500，期限结构（1D/9D/3M/6M）与兜底直连 CBOE 官方日线 CSV。

MOVE / FRED：MOVE 走 Yahoo（curl_cffi）→ TradingView → CSV 三级兜底；HY OAS 走 FRED 官方 API（BAMLH0A0HYM2，日度更新）。
