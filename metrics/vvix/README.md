# VVIX 波动率的波动率可视化

页面：[index.html](index.html)（另见仓库根目录 [README.md](../../README.md)）

## 一句话

**VIX 告诉你市场现在多怕；VVIX 告诉你大家对“怕不怕”有多不确定。**

VVIX 是 CBOE 的 VVIX 指数：用 VIX 期权价格算出的、VIX 本身未来 30 天的预期波动，也就是“波动率的波动率”。

## 三层计算链条

标普 500 期权 → VIX（标普 500 的预期波动）→ VVIX（VIX 的预期波动）

## 读数区间

| VVIX | 区间 | 含义 |
| --- | --- | --- |
| < 80 | 偏低 | 波动率环境稳定、可预测 |
| 80–100 | 正常 | 平静 |
| 100–120 | 偏高 | 典型不确定性 |
| 120–140 | 高 | 不确定性上升，尾部对冲需求起来了 |
| > 140 | 极端 | 高度不确定 / 危机 |

长期中位数在 90 左右；历史范围约 60–220。

## 为什么它有提前量

VIX 还没动、VVIX 先悄悄上去，往往是有人在提前买尾部保险。反过来，VIX 还很高、VVIX 先下来，往往是危机在退潮。

## VIX × VVIX 四种组合

- VIX 低 + VVIX 低：深度自满，对冲便宜
- VIX 低 + VVIX 高：表面平静，但有人在悄悄买保险，值得警惕
- VIX 高 + VVIX 高：恐慌顶点附近
- VIX 高 + VVIX 低：危机在企稳、走向正常化

## 2026-11-20 回放

- VIX：盘中 40.03，收 35.89
- VVIX：收 138.03，低于 2025 年 4 月那次低点的 171
- SKEW：138.84

结论仍是“触及了恐慌，但没确认”：VVIX 偏高但没到极端，期货也显示市场认为 spike 是暂时的。

## 两个常见误读

1. **VVIX 高 ≠ VIX 一定要暴涨**：它测的是 VIX 的摆动幅度，不是方向，VIX 也可能往下走。
2. **不能跨尺子比大小**：VVIX 天然比 VIX 大（90 左右 vs 17 左右的中位数），140 的 VVIX 和 40 的 VIX 不是一个量级的恐慌。
