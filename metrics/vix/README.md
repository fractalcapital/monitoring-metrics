# VIX 恐慌指数可视化

页面：[index.html](index.html)（另见仓库根目录 [README.md](../README.md)）

## 一句话分清

**正式名字：CBOE 波动率指数（VIX），它本身就是标普 500 未来 30 天的隐含波动率；“恐慌指数”只是市场给它的外号，不是官方名称。**

## 它是怎么算出来的

VIX 不是直接看涨跌，是看投资者愿意花多少钱买期权（尤其看跌认沽期权，相当于给股票买保险）。市场害怕大跌、抢着买下跌保险 → 期权变贵 → VIX 读数走高。

## 为什么会被叫恐慌指数

绝大多数时候和标普 500 反向走：

- 股市平稳、大家乐观：VIX 偏低（常 10–20）
- 股市暴跌、危机来了：VIX 飙升

## 历史峰值（收盘口径）

| 事件 | 日期 | VIX 收盘 |
| --- | --- | --- |
| 金融危机 | 2008-11-20 | 80.86 |
| 新冠疫情 | 2020-03-16 | 82.69（历史最高收盘） |
| 关税冲击 | 2025-04-08 | 52.33 |
| AI 下跌 | 2026-11-20 | 35.9（盘中摸到 40.03） |

补充：2008 年盘中最高 89.53（2008-10-24），2020 年盘中最高 85.47（2020-03-18）。

## 一个很关键的误区

**VIX 本质测的是，不是单纯测恐慌。**理论上，大涨的剧烈波动也能推高 VIX，只是现实里美股投资者更怕大跌、很少因为大涨疯狂买看涨期权，所以长期表现成了“恐慌温度计”。

简单类比：VIX = 车险保费。保费涨，不一定代表一定会出事，只代表大家觉得出事概率变高、愿意多花钱买保障。

## 页面内容

- 1990–2026 年 VIX 长图，按平静 / 紧张 / 恐慌分区，点事件标签或圆点看详解
- 峰值排行榜条形图、与标普 500 反向关系的示意图
- 可拖动的读数翻译器：把 VIX 换算成未来 30 天 / 单日预期波动幅度与所在区间
- 六档读数速查表
- 第 07 节“监控仪表盘”：VIX + 期限结构、MOVE、高收益信用利差、VVIX、SKEW 五个指标同页对照，带正常区间刻度尺和 2026-11-20 读数定位。MOVE 与高收益利差在 11 月 20 日当天没有已核实的读数，卡片里只给正常区间与读法，未硬填数值。
