# MOVE 指数可视化

页面：[index.html](index.html)（另见仓库根目录 [README.md](../../README.md)）

## 一句话

**MOVE 是债市的 VIX。**

全名 ICE BofA MOVE Index（Merrill Lynch Option Volatility Estimate），从 2 / 5 / 10 / 30 年美债期权价格算出的、美债收益率未来一个月的隐含波动。单位是基点（年化收益率波动），不是百分比：MOVE 100 大致意味着期权市场定价未来一年收益率有约 100 个基点（1.00%）的波动（一个标准差）。

## 读数区间

| MOVE | 区间 | 含义 |
| --- | --- | --- |
| < 60 | 平静 | 债市安静，利率预期稳定 |
| 60–100 | 中等 | 波动温和 |
| 100–140 | 偏高 | 波动明显，利率 / 美联储预期在修正 |
| > 140 | 极高 | 债市高度不确定 |

换算成单日：MOVE 60 ≈ 每天 3.8bp；100 ≈ 6.3bp；140 ≈ 8.8bp（按年化波动除以 √252 估算）。

## 历史峰值（代表性约数）

| 事件 | MOVE |
| --- | --- |
| 2008 金融危机 | 约 264.6（历史最高） |
| 2023 年 3 月银行危机 | 约 199 |
| 2020 新冠疫情 | 约 164 |
| 2022 年 | 约 158 |

## 为什么只看 VIX 会漏掉它：2022 年的背离

2022 年那轮熊市，VIX 大部分时间都没超过 35，但 MOVE 几个月都在 120–160 之间。那是一轮债市主导的下跌，等 VIX 来确认就晚了。2023 年 3 月也是：MOVE 先冲到约 199，股市波动随后才跟上。

## MOVE × VIX 四象限

- MOVE 低 + VIX 低：风险资产友好，carry、杠杆策略都能跑
- MOVE 高 + VIX 低：债市在报警、股市还没反应过来，最容易漏掉信号的组合
- MOVE 低 + VIX 高：股市情绪宣泄，债市还没出系统性问题
- MOVE 高 + VIX 高：股债同跌、流动性紧张，最危险的组合
